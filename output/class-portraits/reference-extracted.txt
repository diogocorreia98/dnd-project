How to use this reference
Purpose. This file is intentionally optimized for a future image-generation run. It contains the current retained concept, the latest source/version to use, and a concrete visual/narrative instruction for making each build recognizable without re-researching the subclass.
Treat the document as authoritative for this requested set as of the research cutoff. Do not add older or superseded variants that are absent here.
For an older 5e subclass marked as legacy, keep it because no later published replacement existed at the cutoff; combine that subclass fantasy with the current class chassis shown at the start of its class section.
For Warlocks, visually externalize patron influence whenever possible. For Barbarians, make Rage visibly active. Apply the same principle to every class: show what the build is doing, not just what clothes it wears.
A patron, ancestor, beast, spirit, construct, swarm, or other companion may appear as a spectral projection, magical manifestation, blueprint, shadow, or tightly localized summoned effect. It should not become a second fully staged character or an environmental scene.
Preserve the species-neutral base character. Temporary transformations and magical overlays are allowed when they are subclass mechanics, but do not turn thematic motifs into permanent ancestry markers.
For the image batch: create three separate full-body files per combination - Male, Female, Androgynous - each on a genuinely transparent background, with one main character and no scenery, labels, logos, frames, or cropped equipment.

Class index

Barbarian
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show Rage as an active physical state: aggressive forward motion, reckless commitment, heavy martial impact. Any supernatural effect must come from the subclass, not generic glowing magic.

Bard
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show active performance or expressive inspiration magic: voice, instrument, dance, rhetoric, or another art form visibly affecting the scene. The subclass should determine what the performance manifests.

Cleric
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show a holy symbol or ritual focus and unmistakable divine power. The domain must visibly define the shape, symbols, energy, and purpose of that divine manifestation.

Druid
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show primal spellcraft, a druidic focus, or a Wild Shape-linked manifestation. Nature magic should be specific to the circle rather than generic leaves and green glow.

Fighter
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show trained martial competence first: deliberate weapon handling, armor or tactical gear, and a readable fighting stance. Subclass identity should be communicated through combat technique, specialized gear, or its specific supernatural discipline.

Monk
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show disciplined unarmed or monk-weapon movement and controlled Focus energy. The pose should look like a technique in progress, with subclass-specific motion or supernatural expression.

Paladin
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show an oath-bound holy warrior: martial armament plus concentrated divine conviction, typically through a smite, aura, sacred emblem, or oath-shaped manifestation. The oath's values should be legible in the pose and effects.

Ranger
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show a mobile hunter and wilderness specialist with practical tracking gear, ranged or paired weapons, and a clear quarry-focused action. Supernatural effects should express the subclass's hunting method.

Rogue
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show precision, mobility, stealth, deception, or opportunistic attack rather than frontal soldiering. The subclass must explain how this Rogue creates or exploits an opening.

Sorcerer
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show magic erupting innately from the character rather than being learned from a book or granted by an external patron. The origin should visibly shape the energy, posture, and magical geometry.

Warlock
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show pact magic and an external source of power. Whenever possible, make the patron influence narratively visible as a spectral adviser, looming silhouette, tether, reflected figure, symbolic avatar, or other localized manifestation behind or around the Warlock.

Wizard
Current class chassis: Player's Handbook (2024) - Official 5.5e class chassis
Class visual baseline: Show deliberate learned magic: spellbook, arcane notes, prepared sigils, precise gestures, or controlled formulae. The subclass should determine the school or technique being demonstrated.

Artificer
Current class chassis: Eberron: Forge of the Artificer (2025) - Official 5.5e Artificer class chassis
Class visual baseline: Show magic engineered through tools, infusions, runes, devices, armor, alchemy, maps, or constructs. Effects should look designed and operated rather than innate.

Blood Hunter
Current class chassis: Critical Role Blood Hunter, current D&D Beyond version - Partner / Critical Role class
Class visual baseline: Show hemocraft as a deliberate cost: a crimson rite or blood-red occult sigil energizing a weapon, paired with hunter tools and a grim monster-hunting stance.

Gunslinger
Current class chassis: Valda's Spire of Secrets: Player Pack 2 (2026) - Partner / Mage Hand Press class
Class visual baseline: Show firearms as the unmistakable center of the build: practiced gun handling, grit, precision, smoke, casings, and cinematic trick-shot motion rather than generic archery or spellcasting.
